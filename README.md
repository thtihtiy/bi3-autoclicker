Auto-clicker for Debian, Ubuntu, or Windows created with xdotool

- Manual mode: Press once to activate and again to deactivate whenever you want.

- Hold-to-click Holding down the key generates a very high number of clicks (use with caution).

Configuration and usage:
You can modify the click frequency by changing the corresponding setting (repetition 1).

Warning: Setting the click number high or holding down the key for an extended period may cause temporary freezes or lag in Roblox due to the massive volume of clicks. You might sometimes be unable to type in the chat, as Roblox has to process a large number of clicks.

If you are using Windows:
Since this script contains Linux commands, Windows users can run it using the AutoHotkey script I have provided.

(both auto-click modes are included in the same script)
